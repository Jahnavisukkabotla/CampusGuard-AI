# 🛡️ CampusGuard AI

An AI-powered phishing email detection platform designed to help users identify malicious emails and improve cybersecurity awareness.

## 🚀 Features

- 📧 Analyze emails for phishing threats
- 🤖 AI-based email classification
- 📊 Interactive dashboard with email statistics
- 📈 Email trend visualization
- 🕒 Email history tracking
- 🔐 Secure login system
- 🎨 Modern responsive user interface

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Axios
- Bootstrap
- Recharts
- React Icons

### Backend
- Spring Boot
- Spring Security
- REST APIs
- MySQL

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Jahnavisukkabotla/CampusGuard-AI.git
```

### Frontend

```bash
cd campusguard-frontend
npm install
npm run dev
```

### Backend

Import the Spring Boot project into IntelliJ IDEA or Eclipse and run the application.
